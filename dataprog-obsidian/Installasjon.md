## Steg 2.  Virtuelt køyremiljø

+ Last ned `requirements.txt`
+ Opprett køyremiljø
+ Set opp Jupyter med kjerne for køyremiljøet

**NB!** 
Mange av dokumenta som er brukte i kurset vil ikkje verka
utan at det virtuelle køyremiljøet er sett opp som kjerne
i jupyter.

## Steg 3.  Nedlasting av dokument

**NB!**  Nokre program vil ikkje kjenna igjen Jupyter-filer,
og dei kan finna på å endra filnamn eller gjera andre ting
for å opna fila i noko anna enn Jupyter.

+ Jupyter notebook-filer har normalt filending `.ipynb`.
+ Jupyter notebook-formatet bruker JSON.  Dersom maskina
    kjenner att fila som JSON, so er det forsovidt rett,
    men ikkje alle JSON-filer gjev meining frå Jupyter.
