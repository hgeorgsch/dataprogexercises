# Utkast til emneskildring 2025

**Tittel**  Programmering til dataanalyse 

**Fagleg Innhald**
Emnet gjev ein introduksjon til bruk av generell programmering som eit verkty i dataanalyse. Målgruppa er folk som allereie arbeider med kvantitative data i jobben,
anten det er rekneskap, forretningsanalyser, demografi eller finans.
Målet er at programmeringsverkty skal gjera det mogleg å handtera større og meir samansette datasett, automatisere periodisk rapportering og mogleggjera meir avanserte og fleksible analyseteknikkar, som maskinlæring.

+ Ta i bruk Jupyter Lab og Python.
+ Simulering av økonomiske prosessar
+ Formattering og visualisering av datasett
+ Statistisk analyse og maskinlæring
+ Gjenbrukbar kode og automatisering
+ Personvern, sikkerheit og etikk

Kurset opnar for at studentane kan velja ulike tema til fordjuping.

**Læringsutbyte**
+ Kunnskap. Etter endt kurs veit kandidaten
	+ om dei viktigste høve og avgrensingar som programmering,
      maskinlæring og andre digitale verkty gjev til 
      handsaming og analyse av økonomiske data. 
    + om nokre viktige kjelder til opne data.
    + korleis kunstig intelligens bruker data og kva KI
      dermed kan og ikkje kan gjera.
    + kva lover som avgrenser lagring og bruk av data.
+ Ferdigheiter.  Etter endt kurs kan kandidaten
	+ bruka programmering til å henta, formattera, kombinera,
      visualisera og analysera data frå ulike kjelder.
+ Kompetanse. Etter endt kurs kan kandidaten
	+ finna fram relevante data og velja relevante verkty og metodar for å handtera dei.
	+ finna, evaluera og ta bruk nye digitale verkty og prosessar i eigen arbeidssituasjon.
	+ kritisk analysera og tolka kvantitative data i eigen fagkontekst.

**Læringsformer og aktiviteter**
+ Tre samlingar med seminar, øvingar og vegleiing.
+ Videoføredrag og videodemonstrasjonar.
+ Vegleiingstimar på nett
+ Øvings- og prosjektoppgåver 

**Obligatoriske aktiviteter**
Deltaking og munnleg presentasjon av utvalde oppgåver på midtvegssamlinga.  Oppgåvene som vert presenterte kan sidan brukast i mappa.  Ved gyldig fråvêr (sjukdom o.l.) eller om presentasjonen ikkje vert godkjend, kan ein fullføra det obligatoriske arbeidskravet på avslutningssamlinga.

**Mer om vurdering**
Karakteren vert sett på grunnlag av mappa. Oppgåvetekst og vurderingskriterium vert kunngjorde på opningssamlinga.

Der er ingen kontinuasjonseksamen. Kandidatar som er fråverande, får stryk eller som vil forbetra karakteren, må ta heile mappa og dei obligatoriske arbeidskrava på nytt neste gongen emnet vert undervist.  Sjukdom og liknande omstende kan gje grunnlag for utsett levering.

**Anbefalte forkunnskaper**
Yrkeserfaring som inneber handsaming eller analyse av kvantitative data (rekneskap, finans, demografi *eller* anna).

**Kursmateriell** vert kunngjort på opningssamlinga.

**Studiepoengreduksjon**  7½sp IIRA2001, 2½sp INGA1001, 2½sp INGA1002
