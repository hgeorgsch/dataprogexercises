# Uke 34 – Kom i gang med Jupyter og Python

Den første uken handler om å få utviklingsmiljøet på plass og bli trygg på den
grunnleggende arbeidsflyten i en Jupyter Notebook. Python brukes først som
kalkulator før vi begynner å lagre beregninger i variabler.

## Læringsmål

Etter uken skal du kunne:

- bruke enkle terminalkommandoer til å finne og opprette mapper
- kontrollere at Python, JupyterLab, sentrale datapakker og Git er installert
- åpne, lagre og kjøre en Jupyter Notebook
- forklare forskjellen mellom tekstceller og kodeceller
- kjøre celler i riktig rekkefølge og starte kernelen på nytt
- bruke Python til enkle økonomiske beregninger
- opprette variabler og skrive ut resultater
