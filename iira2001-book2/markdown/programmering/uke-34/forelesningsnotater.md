## Jupyter Notebook som arbeidsdokument

Her kan vi forklare:

- hva en notebook er
- forskjellen mellom tekst- og kodeceller
- hvordan celler kjøres
- hva kernelen gjør
- hvorfor cellerekkefølge betyr noe
- hvordan notebooken lagres og leveres

:::{warning} Vanlig nybegynnerfelle
En notebook kan vise gamle resultater selv om koden er endret. Bruk
«Restart kernel and run all» for å kontrollere at dokumentet virker ovenfra og
ned.
:::

## Python som kalkulator

Her kommer eksempler på operatorene `+`, `-`, `*`, `/`, `//`, `%`
og `**`.

```python
pris = 125
antall = 40
inntekt = pris * antall
print(inntekt)
```
