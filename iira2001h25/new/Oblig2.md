# Andre Obligatoriske Innlevering

Prinsippet for den andre innleveringa er det same som for [](Oblig1),
men i staden for å løysa eit problem vha. simulering, skal de løysa eit
problem vha. eksisterande datasett (t.d. frå SSB) som de handsamar i
pandas.  
De vel sjølve kva problem de vil arbeida med og kor amisiøse de vil vera.

+ Levering på BlackBoard
+ **Frist** Sundag 26. oktober (før midnatt natt til måndag).
+ **Format** Eitt Jupyter Notebook-dokument (.ipynb-fil) 
    + De skal skriva eit *essay* som drøftar eit eller anna problem
      som de finn interessant, gjerne fordi det er relevant for
      studiet dykkar.
    + Eit essay, som andre gode historiar, omfattar ei byrjing,
      ein midte, og ei avslutting (Aristoteles *Poetikken*)
        + byrjinga skal ta opp problemet, gjerne med undring,
          slik at lesaren og forfattaren har sams utgangspunkt
        + midten skal utforska problemet, og det er her de bruker
          python for å gjera utrekningar og simuleringar.
        + avsluttinga skal tolka resultat og konkludera, og reflektera
          over kvifor dette er interessant.
    + Der er ingen ordgrense, korkje maksimum eller minimum.  
      De må vurdera behovet for ord opp mot vurderingskriteria.
+ **Innhald** Oppgåva innber
    1. Svar på éi oppgåve innanfor dataanalyse etter eige val.
       Dette vert utforskinga i midten av *essayet*.
    2. Kort refleksjonsnotat (normalt ikkje meir enn 200 ord)
       som forklarer kvifor denne oppgåva er interessant for deg
       (ditt studium/karriereplanar).
       Dette inngår i avsluttinga.
+ **Mål**  Oppgåva skal visa at
    + du kan bruka pandas til å lesa inn CSV-filar, formattera data
      og laga informative og leselege plott.
    + du kan programmering (python og pandas) for å skaffa fagleg
      innsikt i datasett som du hentar frå andre kjelder.
+ **Kunstig intelligens og annan hjelp**
    + Du skal visa at du kan løysa problem og *gå god* for løysingane.
    + Du må gjerne bruka all den hjelpa du kan få til å finna idéar og
      løysingar, men *du* må argumentera for at svaret er riktig og relevant
      for *deg*.
    + Bruker du mykje hjelp, skal du reflektera over det i refleksjonsnotatet,
      og vurdera kva slags hjelp du har brukt, kvifor du har brukt ho, og
      korleis du kan stola på svaret som du ender opp med.
+ **Oppgåve**  Du skal, som sagt, ta for deg eitt praktisk dataanalyseproblem
  som du studerer  vha. python og pandas.
  Som utgangspunkt kan du bruka ei av fylgjande oppgåver, eller ei som du
  finn sjølv.  Alle oppgåvene kan varierast etter eige ambisjons- og
  ferdigheitsnivå.
