
# Obligatorisk arbeidskrav

På midtvegssamlinga skal alle presentera løysing og refleksjon over
éi oppgåve frå den fyrste perioden.  Ein *kan* (men må ikkje) bruka
den same oppgåva som del i vurderingsmappa.  Det er lurt å ha
kriteria for [mappevurderinga](Mappevurdering) i tankane når ein
vel oppgåve.  Presentasjon på samlinga er eit vilkår for å få
levera mappa til vurdering.

Ein kan ta utgangspunkt i ein kvan oppgåve frå den fyrste perioden, 
eller finna på sitt eige problem for å visa liknande teknikkar.
Vil ein gjera det enkelt, kan ein bruka eit gjennomarbeidd døme.
Vil ein vera meir original, skal ein bruka ei meir opa oppgåve.

Presentasjonen på samlinga skal 
1.  Presentera eit problem, og reflektera over kvifor problemet er
    interessant.
2.  Forklara korleis python vert brukt til å opplysa problemet.
3.  Presentera resultata frå utrekninga i python.
4.  Reflektera over korleis python gjev meirverdi og kan styrka
    analysa av problemet.

Tida er avgrensa, so ein kan kanskje berre presentera eitt høgdepunkt
frå analysa.

**Målet** med denne øvinga er å skapa diskusjon i gruppa, og dermed 
bidra til erfaringsutveksling.

**Målgruppa** for presentasjonen er dei andre deltakarane, meir enn
undervisaren.

Ved sjukdom og liknande unnskyldt fråver, kan ein presentera arbeidskravet
på avsluttingssamlinga i staden.
