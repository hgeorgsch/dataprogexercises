# git og github

+ [](Installasjon-git)
+ Oppgåve `git`

## Koma i gang med Git

1. Installer git

2. Opprett *Personal Access Token* (PAT)
    + Sjå [skjermbilete](https://www.geeksforgeeks.org/git/how-to-generate-personal-access-token-in-github/)

```sh
git config --global credential.helper store
```

3. Klon eit repo

```sh
git clone https://hasc@git.ntnu.no/hasc/test.git
```

Bruk PAT i staden for passord
