# Avslutningssamling


+ **Stad:** NTNU i Ålesund, 
  [Brua](https://link.mazemap.com/vdbzfWlm) i Kompasset (K-bygget), 3. etasje.
+ **Dato:** Onsdag 10. og Torsdag 11. juni 2026.  
+ Deltakarpresentasjonar
    + Me har deltakarpresentasjonar etter same mal som på mellomsamlinga.
    + Dei som ikkje presenterte på mellomsamlinga, *må* presentera 
      på sluttsamlinga.
    + Dei som har presentert, treng ikkje å presentera på nytt,
      men er velkomne til å gjera det.
    + Det er lov å bruka presentasjonen til å reisa spørsmål som
      er verd å drøfta i heile gruppa.
    + Eg vil gjerne ha beskjed fra kvar og ein om dei ynskjer å
      presentera.
+ Programmet vert tilpassa talet på presentasjonar.
+ Start- og sluttidene står faste.
