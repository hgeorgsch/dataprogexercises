# Grafiske brukargrensesnitt

Der er sikkert mange som, når dei går i gang med å skriva
frittståande program, drøymer om å laga grafiske brukargrensesnitt (GUI).
Det skal me sjå på denne veka.

Målet er konseptuell forståing av kontrollflyten i GUI-program.
Dei grafiske elementa er enkelt nok å koda med moderne språk.
Utfordringa er at kontrollflyten i programmet ikkje går lineært
frå start til slutt som me er vande med.
Det er brukaren sine handlingar som avgjer kva kode som vert køyrd når.

Det tek nok meir enn ei veke med GUI å læra seg å skriva *nyttige*
program med grafisk grensesnitt, men med grunnkonsepta på plass kan
ein kanskje klara å læra resten på eiga hand.
