# Installasjon git og IDE

I andre halvdel av kurset vil me sjå på ein del ny programvare ved sidan
av Jupyter.  Dette er ikkje obligatorisk for å fullføra kurset, men kan
vera viktig for å forma ein god arbeidsflyt når ein skal bruka programmering
i praksis.  Kvar og ein må vurdera kor mykje ein vil investera i dette temaet.

Me skal snakka meir om dette på midtvegsamlinga, men der er to ting som ein
gjerne bør drøfta med eiga IT-teneste før det.

1.  Ein IDE (*Integrated Development Environment*).
    Her er der mange program å velja mellom.  Eg vil primært presentera
    Spyder, som ein kan installera via `pip`, og som difor ikkje krev førebuing.
    Eg veit derimot at somme bedriftar allereie bruker andre IDEar, som t.d.
    VSCode.  Dersom der er eit miljø for ein slik IDE, so kan det løna seg å
    velja dén heller enn Spyder.
2.  Versjonskontroll, spesifikt `git`.  
    Dette kan ein ikkje installera gjennom `pip`, og mange er dermed nøydde
    til å prata med IT-tenesta for å [](./Installasjon-git).
