# Døme på mappeinnlevering

Eg har freista å sanka nokre døme på *essays* som kan inngå i mappa.
Målet er ikkje å visa perfekte innlevering, men heller som realistiske
døme på duglege innleveringar.  Kvart døme har med ei vurdering ihht.
kriteria for mappevurdering.

+ [](kontantstraum)
   + [](kontantstraum-eval)


Eg vil neppe klara å laga eit døme på refleksjonsdelen (Del 3).
Refleksjon skal vera so individuell at døme lett verkar mot
hensikta si.
